# Current Netlify deployment reference

The ten immutable ZIP archives remain at the repository root because Codex Create PR cannot carry binary rename changes. They are reference material only and are not imported by Astro. Extract them only to a temporary directory for audits; never copy `_next`, `_astro`, generated HTML, or framework bundles into the production source.

See `docs/binary-assets-required.md` for the exact authentic images and PDFs that must be restored manually after this text-only pull request is created.
