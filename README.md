IMPORTANT:
1. Create ONE local folder called:
   four-dogs-current-site-reference

2. Download every ZIP in this set.

3. Extract ALL of the ZIPs into that SAME folder.
   Choose merge/replace folders if your computer asks.

   _next/, and the individual page folders will merge back into the original

   current-site reference.

   four-dogs-current-site-reference

7. Codex should build the clean Website 2.0 source in a DIFFERENT private repo:
   four-dogs-entertainment-website
