5. Update owned Facebook Events, Meetup, or Eventbrite listings using authorized platform access. Do not assume these services provide unrestricted publishing APIs.
6. Record the external listing URL, platform, check date, and website revision from /admin/distribution/ as syncedRevision.
7. Recheck after approval. Correct any price, venue, or time conversion errors.
8. On a change, update the website record first, then every listing whose syncedRevision differs.
